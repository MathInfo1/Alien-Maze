# Alien-Maze
3D Maze, alien theme (still missing), can be played with a Microcontroller and ILI9488 display

# How to play
Setup (Follow release as well): Download the files and upload to the microcontroller. Connect display to microcontroller, adjust pins in main.py if necessary. 

1) Input is on laptop/PC, recommended IDE is Thonny.
2) Move with WASD, turn with J (left) and L (right)

# Infos, Problems, etc.
- Shading is sometimes weird (probably calibration problem): very close parts are darker instead of lighter
- You can go through walls
- Top and Bottom of each wall is not flat (math problem?)
